# ALX · Trading log

Public trading journal of a Tradeify 50K account (MNQ futures): equity curve, journal (calendar, cards, timeline),
a page per trade, statistics and the trading approach. A local admin imports trades from Tradesea and completes them.

```bash
npm install
npm run dev      # http://localhost:3000, admin at /admin
npm run build    # static public site
```

- Data: `data/trades.json` and `data/strategy.json` (edited by the admin, committed to publish).
- Screenshots: `public/shots/`.
- Spec and mockups: `docs/maquette/` (start with `plan/PLAN.md`).
